GEREH REGISTER FIX REPORT
Tarih: 2026-09-06

YAPILAN DEGISIKLIK

SQLite startup initialization sirasinda users tablosu eklendi.

Eklenen ensureUsersTable() fonksiyonu:
- users tablosunu CREATE TABLE IF NOT EXISTS ile olusturur.
- id alanini AUTOINCREMENT primary key olarak tanimlar.
- email alanini TEXT NOT NULL UNIQUE olarak tanimlar.
- password_hash ve name alanlarini NOT NULL olarak tanimlar.
- role, plan ve status alanlari icin mevcut schema ile uyumlu default degerleri korur.
- created_at ve updated_at alanlarini NOT NULL ve CURRENT_TIMESTAMP default ile tanimlar.

ensureUsersTable(), ensurePatternsTable() ve ensurePatternsColumns() cagrisindan once startup sirasinda calistirilir.
Mevcut patterns initialization davranisi degistirilmemistir.
PostgreSQL'e gecis yapilmamistir.
SQLite mimarisi korunmustur.
